Política de Privacidade

Extensão LigaMagic Dark Mode para Chrome

Última atualização: 9 de agosto de 2026

Esta extensão não coleta dados pessoais. Ela não tem servidor, não faz requisições de rede, não usa analytics e não contém código remoto.

O que a extensão guarda

Apenas as três preferências que você escolhe no popup. Cada uma é um liga/desliga:

  • Modo escuro
  • Seguir o tema do sistema
  • Suavizar banners

Elas ficam em chrome.storage.sync, o armazenamento de extensões do próprio Chrome. Não há nome, e-mail, identificador, histórico de navegação, endereço de página visitada, nem qualquer conteúdo da LigaMagic ou de outro site.

Vale ser explícito sobre uma consequência do chrome.storage.sync: se você tiver a sincronização do Chrome ativada, essas três preferências são sincronizadas entre os seus dispositivos pelo próprio Chrome, o que envolve os servidores do Google. Isso é comportamento do navegador, não da extensão, e nesse tráfego não vai nada além dos três liga/desliga. Se preferir evitar até isso, desative a sincronização de extensões em chrome://settings/syncSetup — a extensão continua funcionando normalmente, só deixa de levar suas preferências para outras máquinas.

O que a extensão faz nas páginas

A extensão atua exclusivamente em ligamagic.com.br. Nesse domínio ela injeta duas folhas de estilo e um script pequeno, cuja única função é ligar e desligar uma classe CSS no elemento <html> — é isso que permite alternar o tema sem recarregar a página.

O script não lê o conteúdo da página: não acessa cards, decks, preços, pedidos, dados de conta nem qualquer texto do site. Também não altera nada além da aparência. Em nenhum outro site a extensão é executada.

Compartilhamento com terceiros

Nenhum. Não há venda, transferência ou compartilhamento de dados, porque não há dados coletados. A extensão não se comunica com nenhum servidor — nem com um servidor nosso, que não existe.

Relação com a LigaMagic

Este é um projeto independente, sem qualquer vínculo com a LigaMagic. A extensão apenas altera a aparência do site no seu navegador. O que a própria LigaMagic coleta quando você a usa é regido pela política de privacidade dela, sobre a qual esta extensão não tem influência. Magic: The Gathering é marca registrada da Wizards of the Coast, que também não tem relação com este projeto.

Alterações

Privacy Policy (English)

LigaMagic Dark Mode Chrome extension — last updated August 9, 2026

This extension collects no personal data. It has no server, makes no network requests, uses no analytics, and contains no remote code.

What is stored

Only the three on/off preferences you set in the popup: dark mode, follow the system theme, and soften banners. They are kept in chrome.storage.sync, Chrome's own extension storage. No names, emails, identifiers, browsing history, visited URLs, or page content of any kind.

To be explicit about one consequence of chrome.storage.sync: if you have Chrome Sync enabled, those three preferences are synced across your devices by Chrome itself, which involves Google's servers. That is browser behaviour rather than extension behaviour, and nothing beyond the three toggles travels with it. You can disable extension sync at chrome://settings/syncSetup and the extension keeps working.

What it does on pages

The extension runs only on ligamagic.com.br. There it injects two stylesheets and a small script whose only job is to toggle a CSS class on the <html> element, which is what allows switching the theme without reloading.

The script does not read page content — no cards, decks, prices, orders, or account data — and changes nothing but appearance. It does not run on any other site.

Permissions

  • storage — remember the three popup preferences.
  • activeTab — when the popup opens, read the active tab's URL solely to compare its hostname and warn if the tab is not a LigaMagic page. The URL is never stored or transmitted.
  • Host access to ligamagic.com.br — apply the dark theme. This is the extension's purpose.

Third parties

None. No data is sold, transferred, or shared, because none is collected. The extension communicates with no server.

Relationship to LigaMagic

This is an independent project with no affiliation to LigaMagic. Whatever LigaMagic itself collects is governed by its own privacy policy. Magic: The Gathering is a trademark of Wizards of the Coast, which is likewise unaffiliated with this project.
